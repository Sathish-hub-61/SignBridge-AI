# SignBridge AI 🤟🗣️

> **Context-Aware Voice for Indian Sign Language (ISL) Signers**  
> *Student Capstone Project for Generative AI*

SignBridge AI gives a deaf or speech-impaired person who uses Indian Sign Language (ISL) a **VOICE** when talking to a hearing person who does not know sign language.

The communication is **ONE-WAY: only the signer speaks**. The system is **NOT a chatbot** and does not reply to the signer. A webcam stream is converted to body/hand/face landmarks, a sequence recognition model converts the signing into recognized sign tokens (glosses), and a Generative AI layer (OpenRouter LLM) uses conversation context, scenario, and signer profile to turn those glosses into a natural, grammatical, first-person English sentence in the signer's voice. The sentence is shown as large text and spoken aloud with text-to-speech (TTS) so the hearing person can listen or read.

---

## 🔒 Privacy & Core Invariants

- **Zero Video Egress:** All camera frames are processed directly inside the user's browser via `@mediapipe/tasks-vision`. Raw video **never** leaves the browser.
- **Minimal Transmission:** Only numerical landmark coordinate arrays reach the local backend; only token text reaches OpenRouter.
- **One-Way Invariant:** No hearing-person speech-to-text, no chatbot replies to the signer, no assistant persona.
- **Fidelity over Fluency:** Speaks in first person strictly *as the signer*. Fixes grammar and adds context without ever inventing facts or entities.
- **Training/Serving Parity:** Models are trained on landmarks generated by the identical browser MediaPipe pipeline used at runtime.

---

## 🏗️ 9-Stage Pipeline

```
[1. Webcam Video in Browser]
       │
[2. Video Preprocessing: sampling, normalization]
       │
[3. Feature Extraction: MediaPipe hands, pose, face]
       │
[4. Sign Recognition: Sequence model -> sign tokens + confidences]
       │
[5. Recognized Text: Editable token chips (human-in-the-loop)]
       │
[6. Context Understanding: Rolling history + scenario + profile]
       │
[7. Generative AI/LLM: Compose single first-person sentence via OpenRouter]
       │
[8. Text Output: High-contrast large text for listener]
       │
[9. Speech Output (TTS): Spoken aloud in signer's voice via browser SpeechSynthesis]
```

## 🚀 Quickstart

### 1. Configuration
```bash
cp .env.example .env
# Edit .env with your OPENROUTER_API_KEY if testing live LLM features.
# If no key is set, the system safely falls back to deterministic offline rules.
```

### 2. Backend Setup
```bash
cd backend
python -m venv venv
# Activate venv:
# Windows: .\venv\Scripts\Activate.ps1
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
pytest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) (or the port allocated by Vite) in your browser.
