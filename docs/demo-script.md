# SignBridge AI — 5-Minute Capstone Demo Script

## 1. Intro (1 min)
- Introduce problem: Deaf individuals communicating at hospital desks or daily services.
- Highlight innovation: Existing solutions stop at sign-to-text; SignBridge provides full contextual Generative AI conversation with privacy-preserving edge landmarks.

## 2. Live Demo (3 min)
- **Flow A (Mock Mode):** Demonstrate typed glosses `HELP PAIN DOCTOR` -> Stage A Intent (`emergency`/`request`) -> Stage B empathetic concise spoken reply with quick actions.
- **Flow B (Live Video / Landmarks):** Real-time landmark tracking in browser, confidence-shaded token chips, editable chip verification, synthesized TTS response.
- **Flow C (Show to Others):** Fullscreen accessible high-contrast view for hearing bystanders.

## 3. Fallback Plan (Contingency)
- If camera fails: Toggle Mock Mode to showcase complete LLM conversational layer.
- If OpenRouter API has high latency: Automatic local deterministic rule-based fallback demo.
